# ZUBA Partner portal — GitHub Pages izdanje

Ovaj folder sadrži statički demo spreman za GitHub Pages. Podaci su ilustrativni, a izmene se brišu pri osvežavanju stranice.

## Objavljivanje bez komandne linije

1. Otvorite novi public repository na GitHubu, na primer zuba-partner-portal.
2. Raspakujte ZIP. U GitHub repozitorijumu izaberite Add file → Upload files.
3. Prevucite sadržaj foldera koji ste raspakovali (index.html, assets, products, SVG slike), ne sam ZIP niti nadređeni folder. Potvrdite sa Commit changes.
4. Otvorite Settings → Pages. Pod Build and deployment odaberite Deploy from a branch, zatim main i / (root), pa Save.
5. Kada GitHub završi objavu, adresa će biti https://VAŠ-USERNAME.github.io/zuba-partner-portal/ ako je tako nazvan repository.

Na prijavi možete izabrati demo kupca ili administraciju jednim klikom. Ručna demo lozinka je Demo2026!.

## Izvorni kod

Izvorni projekat je dostupan zasebno. Ovaj ZIP je već izgrađena statička verzija, namenjena jednostavnom GitHub Pages uploadu.
